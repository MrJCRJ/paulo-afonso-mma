# PA FIGHT TEAM

Recriação do site **PA FIGHT TEAM — Equipe Mendonça Júnior** (Muay Thai & Boxe, Paulo Afonso-BA).

## Stack

React + Vite + Tailwind CSS v4 · Framer Motion · React Router

## Rodar

```bash
cd /home/treegunn/Projetos/paulo-afonso-mma
npm install
npm run dev
```

## Configuração rápida

Edite `src/lib/siteConfig.js`:

- `SITE.whatsapp` — número com DDI (placeholder `5599999999999`)
- `PIX_KEY` / planos / horários / endereço

## Demo

- Login → **Entrar como aluno** ou **Entrar como admin** (localStorage)
- Matrícula abre WhatsApp com mensagem montada
- Admin enxuto: matrículas locais + confirmar pagamentos demo + reset

## Build

```bash
npm run build
npm run preview
```
